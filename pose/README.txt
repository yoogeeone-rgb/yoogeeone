편집 기준
첨부된 114쪽 PDF의 전체 텍스트를 한국어로 번역했습니다.
사진·설명 연결을 유지하며, 재배치에 따라 좌우·상하 사진 지시어를 사진 번호로 고쳤습니다.
사진을 탭해 보는 웹 화면에서는 각 페이지의 사진을 원문 리소스 순서대로 표시합니다.
촬영 팁과 탐색용 제목은 편집상 추가한 것으로, 원문 해설과 구분합니다.
본문의 두 군데 편집 잔재 TEXT는 번역에서 제외하되 JSON 매핑에는 빈 항목으로 남겼습니다.
사진 원본의 비율과 내용을 유지했습니다. 원문 PDF의 일부 삽입 사진은 잘려 있었으므로 재배치본에서는 온전한 사진이 보입니다.
사진 속 원본 색상 삼각형은 같은 뜻의 글자 상태 표시로 바꿨습니다.
